# Bitácora

Registro cronológico de la instalación. La regla es simple: se escribe mientras pasa,
no al final. Un error con el mensaje textual y la resolución vale más que cualquier
resumen prolijo posterior.

## Formato

```
## <fecha> — <etapa>
Qué hice:
Qué falló (mensaje literal):
Cómo lo resolví:
Qué aprendí:
Tiempo invertido:
```
